🖥 Нужны компьютеры под рендер

Бот делает видео из реплеев osu!. Считает их сервер, а он слабый — два
ядра на всё. Почти любой домашний компьютер быстрее в несколько раз.

Если у тебя есть комп, который часто простаивает, он может рендерить за
всех. Выключать можно когда угодно: ничего не сломается, просто станет
медленнее.

Что это с тебя возьмёт — ничего заметного. Программа сама смотрит на
заряд батареи, нагрев и на то, сидишь ли ты за клавиатурой, и берёт
столько, чтобы ты этого не почувствовал. Сел играть — одна строка в
файле, и она вообще ничего не берёт, пока ты не вернёшь.

Что нужно поставить: Python 3.12, Rust, ffmpeg. Минут двадцать, один раз.

Как начать: напиши мне, я дам токен. Дальше по инструкции — там всё по
шагам, включая где взять ключи osu! и что делать на Windows:

https://onenineeightfour.ignorelist.com/guide

Если коротко, выглядит это так:

git clone https://github.com/NaumRedlo/1984.git
cd 1984
python3 -m venv venv
./venv/bin/pip install -r requirements-worker.txt
cd dossier && cargo build --release && cd ..

Потом токен в ~/.dossier/worker.env — и:

./venv/bin/python scripts/render_worker.py --check

Эта команда ничего не делает, только проверяет и говорит, чего не хватает.
Когда напишет ready — запускай:

./venv/bin/python scripts/render_worker.py
